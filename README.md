# AquaSense: Cloud-Based Water Usage Anomaly Analytics and AI Conservation Advisor

AquaSense is an AI-powered cloud data analytics platform designed to analyze water-consumption data, identify unusual consumption patterns, investigate anomalies using AI agents, and provide evidence-grounded insights and conservation recommendations using an LLM.

## Architecture
- **Frontend**: Next.js, TypeScript, Tailwind CSS
- **Backend**: Python, FastAPI
- **Cloud/Data**: Supabase
- **AI Agents**: LangGraph, LangChain, OpenRouter LLM
